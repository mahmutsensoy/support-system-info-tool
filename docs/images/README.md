# Ekran Görüntüleri

Bu klasöre README'de kullanılan ekran görüntülerini ekleyin.

## Gerekli dosyalar

| Dosya adı | Ne çekilmeli? |
|-----------|---------------|
| `console-output.png` | `dotnet run` çalıştıktan sonra konsoldaki rapor çıktısı |
| `report-file.png` | Oluşan `sistem-raporu_*.txt` dosyasının Not Defteri veya VS Code'da açık hali |

## Nasıl eklenir?

1. Uygulamayı çalıştırın: `dotnet run`
2. **Win + Shift + S** ile ekran görüntüsü alın
3. PNG olarak bu klasöre kaydedin (yukarıdaki dosya adlarını kullanın)
4. GitHub'a push edin — README otomatik olarak bu görselleri gösterir

## İpucu

- Kişisel bilgi (gerçek IP, MAC, bilgisayar adı) görünmesin istiyorsanız örnek makinede çekin veya görüntüyü kırpın
- PNG formatı GitHub'da en iyi sonucu verir
